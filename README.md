## 🔄 How to Run My Tests:

### Selenium Tests (Java)
1. Clone the repository:  
   `git clone https://github.com/your-username/your-username.git`
2. Navigate to the `test-automation/selenium/` directory.
3. Install dependencies with Maven:  
   `mvn install`
4. Run the tests:  
   `mvn test`

### Cypress Tests (JavaScript)
1. Clone the repository:  
   `git clone https://github.com/your-username/your-username.git`
2. Navigate to the `test-automation/cypress/` directory.
3. Install dependencies:  
   `npm install`
4. Run the tests:  
   `npx cypress open`
